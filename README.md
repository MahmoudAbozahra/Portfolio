# Mahmoud Abozahra Portfolio

Production portfolio and CMS with a React/Vite frontend and Express/MongoDB backend.

- Frontend: `portfolio-fronend/` (name retained for deployment compatibility)
- Backend: `portfolio-backend/`
- Architecture audit: `docs/architecture-audit.md`
- Architecture: `docs/architecture.md`
- Design system: `docs/design-system.md`
- Deployment and security handoff: `docs/deployment.md`

Local commands are `npm ci && npm test` in the backend and `npm ci && npm run build` in the frontend. Copy `portfolio-backend/.env.example` to a local untracked `.env` and provide your own values. Never commit credentials.
